# novel-deepread

Visit: https://cissy0802.github.io/novel-deepread/

小说精读 —— **把故事讲成故事，然后一起想**。

姊妹站「每日精读」(deep-reading) 做的是提纯：把一本厚书反复绕的那几个概念拎出来讲透。那套办法
用在小说上会把小说讲死——**小说的价值不在论点，在「你跟着一个人走了一遍，然后再也回不到原来
那个自己」**。

所以这里每篇干两件事：

1. **把整个故事重讲一遍**（分幕、有画面、有人物动机的叙述，不是梗概），再挑几个最有力量的场面
   慢镜头重演，顺带讲清它为什么有力量。
2. **伏笔与因果写在行文里**——在兑现的那一段当场点透：它埋在哪一幕、当时看着像什么、这一手为什么
   漂亮；正文里另有可点跳的「伏笔 ①→回收 ①」标记，让人一键跳回当初那句毫不起眼的话。**不做对照表**
   ——这些是正文里最好看的部分，不该被搬到附录里。
3. **讲完了一起想**——故事逼出来的那些没有标准答案的两难，每一边都讲到最强，不给结论。

**本站全剧透**，每页开头明说。理由很简单：思考建立在结局之上。目标是「读完这页 ≈ 读过这本小说，
并且比很多读过的人想得更远」。

## 读什么

站从 **刘慈欣「地球往事」三部曲**开篇（BigCat 指定的起点），随后走 **必读小说 Top 100** 主榜。

主榜不是拍脑袋定的：**Claude Opus 5 / GPT-5.5 / Gemini 3.1 Pro 各出一份「一生必读小说 Top 100」，
去重合并共 143 部**——62 部三家全票（★★★）、33 部两家推荐（★★），再由站方补入 5 部填缺口，
凑成 Top 100。排序按三家排名的合并得分。三家都被要求中外兼顾、跨时代跨类型，所以这不是一份
英美文学榜：中文作品 22 部，另有俄、法、德、日、拉美、中东欧、南亚、非洲、阿拉伯、土耳其。

选题源：本仓库 `TOPICS.md`（BigCat 人工维护，routine 只读不改）。写作规范见 `CLAUDE.md`。

原文引用严格克制：情节与设定完整复述，但语言全部自己写，整篇原文引用不超过 200 字，不提供任何
形式的全文。
